= Labs Automated Texture Builder

@parameters

Builds visible USD MaterialX material subnetworks in Solaris from a folder of
textures. It recognizes common OpenPBR texture names, UDIM tiles, and nested
texture folders. Choose OpenPBR Surface or MaterialX Standard Surface.

The tool can reference source images directly, generate incremental TX files
with Houdini's bundled maketx/OIIO tools, or consume an existing TX folder.
Color textures follow the active Houdini OCIO configuration; data textures are
read as Raw. Generated materials support UDIM, repeating UVs, hex pattern
breakup, triplanar projection, and triplanar breakup using standard MaterialX.

@examples

See the companion Automated Texture Builder Solaris example for a two-material
UDIM and automatic-assignment setup.
