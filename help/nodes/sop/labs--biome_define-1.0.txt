= Labs Biome Define =

"""Define the biome attributes for the Biome Toolset."""

This node creates the dictionary attribute `biome_definition` used in the rest of the Biome Toolset. It is used to define all of the characteristics of an individual biome and the user's preference for future visualization. Multiple of these nodes can be chained together to define a full library of biomes. The [Labs Biome Definitions File SOP|Node:sop/labs--biome_definitions_file-1.0] can take a chain of these nodes as input to help read and write the biome library from a `.json` or `.bgeo` file. The second input of the [Labs Biome Attributes to Terrain SOP|Node:sop/labs--biome_attributes_to_terrain-1.1] expects a chain of __Biome Plant Define SOP__ nodes or the output of the __Biome Definitions File SOP__ set to create geometry.

:box:
    #display: raised

    This node's viewport UI features the Whittaker Biome Diagram, originally proposed by Robert Harding Whittaker (1975), modified by Robert Eric Ricklefs (2000). The exact [image|https://commons.wikimedia.org/wiki/File:Climate_influence_on_terrestrial_biome.svg] this node used was released under the [CC0 1.0 Universal|https://creativecommons.org/publicdomain/zero/1.0/deed.en] license.


@parameters

    == Biome ID ==

    Name:
        #id: biomename
        Name of the biome. Do not include spaces.

    Color:
        #id: biomecolor
        Color that is applied to the biome visualizer.

    == Temperature ==

    Average:
        #id: tempaverage
        Average annual temperature (in °C) of this biome.

    == Precipitation ==

    Average:
        #id: precaverage
        Average annual precipitation (in mm) of this biome.

    == Tags ==

    Soil:
        #id: soil
        When enabled, plants will grow in this biome.
