= Labs Dissolve Flat Edges =

"""Removes edges on flat surfaces."""

:video:
    #src:/movies/dissolveflat.mp4

This node identifies and dissolves flat edges. By default, it only detects perfectly flat edges. Using Max Edge Angle to adjust the flatness threshold, will allow mostly flat edges to be dissolved or set higher for artistic decimation.

@parameters

    Group:
        #id: basegroup
        Subset of primitives to dissolve flat edges.

    == Flat Edges ==

    Max Edge Angle:
        #id: maxedgeangle
        Threshold of flatness. A value of `0` means edges have to be perfectly flat, while higher numbers will find more edges and dissolve them.

    Collinearity Tolerance:
        #id: coltol
        Points within this angle of being on a straight line are considered inline.

    == Inline Points ==

    Remove Inline Points:
        #id: removeinline
        Remove inline points of edges that got preserved on the silhouette of the input geometry as a result of the dissolving of flat edges step.

    Distance:
        #id: distance
        Threshold distance for collinearity.
    
    Preserve Attribute Boundary:
        #id: useattribute
        When enabled it will protect edges that represent boundaries of attribute values.

    Attribute:
        #id: attrib
        The attribute used to protect edges that represent boundaries of attribute values.
