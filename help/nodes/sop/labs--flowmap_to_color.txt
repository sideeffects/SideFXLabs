= Labs Flowmap to Color =

""" Converts the flowmap data to vertex colors """

This node converts the flowmap data to vertex colors, which is useful for baking to texture or as encoded vertex data. The tool internally converts the flowmap data to the correct tangent space as well.

@parameters
    Flip Green Channel (Unity):
        #id: flip_g
        This allows you to invert the green channel of the flowmap colors, which is required for it to work in Unity.
