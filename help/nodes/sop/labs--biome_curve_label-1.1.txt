= Labs Biome Curve Label =

"""This node sets the necessary attributes on curves created in Houdini to use with _Labs Biome Region Assign SOP_."""

Instead of the biome interface handled through [_Labs Biome Region Assign SOP_|Node:sop/labs--biome_region_assign-1.2] for all other region assignment methods, this node assigns the necessary attributes to curves as they are created. The first input is the chain of biome definitions generated from [_Labs Biome Define_|Node:sop/labs--biome_define-1.0], the second input is the corresponding curve/primitive, and the third input is the Previous __Labs Biome Curve Label__ SOP in the chain. For curves that can share a biome assignment, it is possible to merge them together first before wiring into the second input. The resulting Biome Regions output is wired into the third input of _Labs Biome Region Assign_.


@parameters

    Biome Name:
        #id: biome
        The biome to assign this region. To adjust biome names, settings, or add/delete biomes, see _Labs Biome Define_.
        
    Sort Order:
        #id: biomehierarchy
        The priority to assign to the associated curve(s). A lower number will give the biome greater priority when resolving overlapping regions, putting it on top of regions with higher values. Biomes with the same value will have their biome attributes averaged. 
        
    Create Next :
        #id: createnext
        Creates the _Biome Curve Label_ node for the next curve region and connects the related wires.
