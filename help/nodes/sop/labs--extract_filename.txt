= Labs Extract Filename =

"""Stores the filename of a file SOP as its detail attributes to be then used in other SOPs."""

This node makes extracting filenames from files imported with a [File SOP|Node:sop/file] very easy. This is extremely useful when processing large number of meshes in batch, and you want to utilize file names for ex baking outputs.

NOTE:
    The tool requires a [File SOP|Node:sop/file] to be plugged in as the direct node above it in order to function properly when using the default input mode.

@parameters
    == Input ==

    Input:
        #id: inputmode
        The mode used to determine which [File SOP|Node:sop/file] should be used to extract the path attributes from. 
    
    File SOP:
        #id: customfilesop
        When __Input__ is set to Custom [File SOP|Node:sop/file], the path (can be relative) in this parameter will be used to extract instead.
    
    == Output ==

    Full Path Attribute:
        #id: fullpath_attribute
        This is the detail attribute name that will be used to store the full file path in. (ex C:/Folder/box.fbx)
    
    File Path Attribute:
        #id: filepath_attribute
        This is the detail attribute name that will be used to store the file path in. (ex box.fbx)
    
    Filename Attribute:
        #id: filename_attribute
        This is the detail attribute name that will be used to store the filename in. (ex box)
