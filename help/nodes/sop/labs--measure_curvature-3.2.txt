= Labs Measure Curvature =

"""Measures the convex and concave curvature of a mesh."""

This node measures the curvature of a mesh and outputs the result as point color.

There are different methods to calculate the curvature including Volume Analysis, Polynomial Fitting, Tensor - Integral, Tensor - Euler, Shape Operator, Approximated Shape Operator, or using the [Measure SOP|Node:sop/measure].

@parameters

    Method:
        #id: method
        Options for the algorithm to calculate the curvature. 
    
    Sample Resolution:
        #id: sampleresolution
        Adjusts the size of the voxel grid when __Method__ is set to `Volume Analysis`.
    
    Per Piece:
       #id: perpiece
       Calculates curvature independently for each named piece.
    
    Piece Attribute:
        #id: pieceattr
        The primitive attribute to be used for looping over geometry internally.

    == Convexity ==
    
    Multiplier:
        #id: convexitymult
        Multiplies the calculated convex values of curvature.

    Blur Amount:
        #id: convexityblur
        Blurs the calculated convex values of curvature on neighboring points to produce a smoother result.

    Remap Convexity:
        #id: convexityremap
        Enables remapping for the convex values of curvature.

    Remap Range:
        #id: convexityramp
        Remaps the linear 0 to 1 values calculated internally.

    Convexity Attribute:
        #id: convexityattr
        Point attribute for the convex values of curvature.

    == Concavity ==

    Multiplier:
        #id: concavitymult
        Multiplies the calculated concave values of curvature.

    Blur Amount:
        #id: concavityblur
        Blurs the calculated concave values of curvature on neighboring points to produce a smoother result.

    Remap Concavity:
        #id: concavityremap
        Enables remapping for the concave values of curvature.

    Remap Range:
        #id: concavityramp
        Remaps the linear 0 to 1 values calculated internally.

    Concavity Attribute:
        #id: concavityattr
        Point attribute for the concave values of curvature.

    == Visualization ==

    Visualize Output:
        #id: viscolor
        Visualizes the concave and convex attributes as colors.

    Convexity Color:
        #id: convexitycolor
        Color of the convex values of curvature.

    Concavity Color:
        #id: concavitycolor
        Color of the concave values of curvature.
