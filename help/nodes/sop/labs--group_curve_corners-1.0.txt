= Labs Group Curve Corners =

""" Creates groups for inside and outside corner points by angle """

@parameters

    Group:
        #id: group
        The point group to apply group curve corners operation to. If blank, the entire geometry will be used.

    Min Inner Angle:
        #id: mininnerangle
        The minimum angle of the inner points. Points with an angle greater than this value will be grouped.

    Max Inner Angle :
        #id: maxinnerangle
        The maximum angle of the inner points. Points with an angle less than this value will be grouped.

    Min Outer Angle :
        #id: minouterangle
        The minimum angle of the outer points. Points with an angle greater than this value will be grouped.

    Max Outer Angle :
        #id: maxouterangle
        The maximum angle of the outer points. Points with an angle less than this value will be grouped.
    
    == Output ==

    Inside Group:
        #id: insidegroup
        The name of the inside group.

    Outside Group:
        #id: outsidegroup
        The name of the outside group.

    Inside Attribute:
        #id: insideattrib
        The name of the inside attribute.
    
    Outside Attribute:
        #id: outsideattrib
        The name of the outside attribute.

    Add Angle Attribute:
        #id: angleattrib
        Exports the angle of change between points as an attribute.

    Add Directional Normal:
        #id: adddirectionalnormal
        Exports the directional normal.
