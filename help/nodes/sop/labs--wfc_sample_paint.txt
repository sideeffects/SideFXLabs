= Labs WFC Sample Paint =

""" A utility tool to paint attribute values on a grid used by the [Labs 2D Wave Function Collapse|Node:sop/labs--2d_wavefunctioncollapse] """

The WFC Sample Paint tool allows you to interactively set values on a grid used by the [Labs 2D Wave Function Collapse|Node:sop/labs--2d_wavefunctioncollapse] (Solver) node.
It also sets up the required attributes in the correct way for the solver. To start using the tool, plug in the [Labs WFC Initialize Grid|Node:sop/labs--wfc_initialize] you want to modify into the first input, and geometry containing a name attribute into the second input.
You can then press the Initialize Value Mapping with Input button to import your geometry to paint with, which will be put into the multiparm. These are the values that will be assigned to the grid.

Once the multiparm has been initialized, enter the node state to start painting the grid. To enter the node state, select the node and press Enter in the viewport.
Click or drag the cursor over points to assign values. Use the scroll wheel to cycle through the values initialized in the multiparm.


@parameters
    == Tool ==

    Objects:
        #id: mpPaintObjects
        The multiparm containing the values initialized from the input geometry.

    Objects:
        #id: sObject_#
        A module that can be painted onto the grid, identified by its assigned value.
