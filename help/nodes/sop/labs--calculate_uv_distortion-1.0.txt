= Labs Calculate UV Distortion =

"""Calculates the UV distortion of a mesh."""

This node calculates the UV distortion for a specified `UV` attribute and exports it as a primitive attribute.  Additionally, there's an option to visualize the distortion using a heat map.

NOTE:
    The tool generates attribute values that are generally centred around `0`, indicating no distortion. Values higher than `0` suggest that a primitive is being compressed, while negative values indicate significant stretching.


@parameters
    Group:
        #id: group
        The selection of primitives to calculate the UV distortion.

    UV Attribute:
        #id: uvattribute
        The attribute to be used for calculating UV distortion.
    
    Output Attribute:
        #id: distortionattribute
        The primitive attribute that is created storing the distortion amount.
    
    Visualize UV Distortion:
        #id: visualize
        Enables a color map that visualizes the UV distortion.
